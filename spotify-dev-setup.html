Set up Spotify developer access

Hitster uses Spotify to find tracks and control the host’s music. Spotify apps in development mode only work for the app owner and a small allow-list of test users. This page explains the quick route for a friend and the full route for your own copy of the game.

Fastest: ask the app owner to add you

Use this when you are playing a friend’s published Hitster game. You do not need to edit code or create your own app.

  1. 1Send the host the email address on your Spotify account.
  2. 2The app owner opens the Spotify Developer Dashboard, chooses the app, then opens Settings → Users Management → Add new user.
  3. 3After the owner has added you, open Hitster and choose Connect Spotify using that same Spotify account.

Spotify currently limits a development-mode app to five authenticated users. If the list is full, the owner must remove an old tester or use Spotify’s extended quota process.

Make your own developer copy

  1. 1. Create a Spotify app. Sign in at the Developer Dashboard and choose Create an app. Give it a name such as “My Hitster”. The app owner needs an active Spotify Premium subscription while the app is in development mode.
  2. 2. Add the two exact redirect URLs. In the app’s Settings, add these to Redirect URIs after you publish your copy:
    https://YOUR-NAME.github.io/YOUR-REPOSITORY/party.html https://YOUR-NAME.github.io/YOUR-REPOSITORY/Jam.html

    The address must match exactly, including capital letters, path, and any trailing slash. Spotify requires HTTPS for published web redirects.

  3. 3. Copy only the Client ID. Replace the CLIENT_ID value near the top of both game HTML files, then publish the files. This game uses PKCE, so never put a Client Secret in an HTML file or share it with players.
  4. 4. Add your hosts as test users. In Settings → Users Management, add each Spotify email that should be allowed to sign in. The player remotes do not need Spotify access merely to join the room; only the person hosting music does.

Party

Party plays music in the host browser with Spotify’s Web Playback SDK. The host must use Spotify Premium. Guests use their phones as game remotes; they do not need their own Spotify sign-in.

Jam

Jam controls the host’s active Spotify device and can keep the game in step with its play and pause state. Start the music on the host’s Spotify device first, then connect Spotify in Jam.

Common errors

  • “Invalid redirect URI”: copy the full published page address into Spotify’s Redirect URIs, save, then try again.
  • Login succeeds but the game cannot use Spotify: check that the account’s exact Spotify email is on the app’s test-user list.
  • Party cannot play music: verify that the hosting account is Premium and that the browser is allowed to play audio.
  • You changed the Client ID: publish the edited HTML and wait for GitHub Pages to deploy before retrying.

Spotify access is only used to run the game’s music features. Hitster never needs your Spotify password.
