Simple setup guide

Make your own Hitster Party

This gives you your own copy of Elad's game and your own Spotify developer app. Follow the steps in order. You only need a GitHub account and a Spotify Premium account for the person who hosts the music.

Before you start

  • You need a free GitHub account.
  • The music host needs Spotify Premium.
  • Players joining the room do not need Spotify or developer setup.

Do these six steps

  1. 1. Copy Elad's game to your GitHub account

    Open github.com/eladbiller/Hitster. Press Fork in the top-right corner, then press Create fork. You now have your own copy; leave its name as Hitster to make the next steps easiest.

  2. 2. Turn on your free game website

    In your copied repository, open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then press Save.

    After about one minute, your Party page will be:
    https://YOUR-GITHUB-NAME.github.io/Hitster/party.html

  3. 3. Create a Spotify developer app

    Open the Spotify Developer Dashboard, sign in, choose Create an app, give it any name (for example, My Hitster Party), accept the terms, and create it.

  4. 4. Add your exact Party address to Spotify

    Inside the Spotify app, open Settings. Under Redirect URIs, add your Party page address exactly as it appears in Step 2, then press Save.

    It must match exactly: use https, your GitHub name, Hitster, and party.html. Do not add a slash at the end.

  5. 5. Put your Client ID into your copy of the game

    In Spotify, copy the Client ID. In your GitHub copy, open party.html and press the pencil icon to edit it. Find this line:

    const CLIENT_ID = 'bc721809b5344694abc164c34249aea1';

    Replace only the letters and numbers between the quotes with your Client ID. Scroll down and press Commit changes.

    Never copy the Client Secret into the HTML. This game only needs the Client ID.

  6. 6. Allow your Spotify account, then play

    Go back to your Spotify app's Settings → Users Management. Press Add new user and add the Spotify email of every person who will host music, including yourself. Then open your Party link, press Create Room, and connect Spotify.

Sharing with friends

For a normal Party game, only the person playing music needs to be a Spotify developer user. Everyone else simply opens the QR code or joins with the room PIN. Spotify development mode allows up to five authenticated Spotify users, so add only people who will host music.

If something goes wrong

“Invalid redirect URI”
Go back to Spotify Settings and paste your complete live Party address again. The address must be identical.
Spotify login works, but Party does not
Open Users Management and add the host's exact Spotify email. Then wait a minute and try again.
Music will not start
Check that the host account is Spotify Premium, then tap the Play Song button once in Party.
Your page still has the old Client ID
Wait for GitHub Pages to finish deploying, then refresh the page completely.

Based on Elad Biller's Hitster code. Spotify access is used only to run music in your game; the game never asks for your Spotify password.
