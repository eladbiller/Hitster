Use your own Spotify with Hitster Party

If Elad has not added your Spotify account to his developer app, you can create your own Spotify app and paste its Client ID into Party. It is saved only on your device. You do not need to copy code or publish a website.

What you need

  • A Spotify Premium account for the person hosting music.
  • A few minutes to create a free Spotify developer app.
  • Players joining the room do not need Spotify, a Client ID, or developer access.

First: phone users need Desktop site

Spotify’s developer dashboard is much easier to use in its desktop layout. If you are setting this up on a phone, turn on Desktop site before you try to create the app.

Android / Chrome
Tap ⋮ in Chrome, then turn on Desktop site.
iPhone / Safari
Tap aA in the address bar, then choose Request Desktop Website.

Then open the Dashboard link below, sign in with the same Spotify account that will host the music, and continue.

Five simple steps

  1. 1. Open Spotify Developer Dashboard and sign in

    Open the Spotify Developer Dashboard and sign in with the Spotify account that will host music in Party. On a phone, make sure you turned on Desktop site first. You should now see a Create app button.

  2. 2. Create your Spotify developer app

    Press Create an app, give it any name (for example, My Hitster), accept the terms, and create it.

  3. 3. Add this exact Redirect URI

    Open your new app’s Settings. Under Redirect URIs, paste this exact address and press Save:

    https://eladbiller.github.io/Hitster/party.html

    Copy it exactly. No extra slash, no spaces, and do not use the Jam address.

  4. 4. Allow yourself to use the app

    Still in your Spotify app, open Settings → Users Management. Press Add new user and add your Spotify email address. Add any other person only if they will host music with your Spotify app.

  5. 5. Paste the Client ID into Party

    Copy your app’s Client ID from Spotify. Open Hitster Party, press Create Room, then press Use your own Spotify Client ID. Paste the Client ID, press Use this Client ID, then log in with Spotify.

    Paste the Client ID only. Never paste or share the Client Secret.

Good to know

  • Your Client ID is saved only in the browser where you pasted it. On another phone or browser, paste it again.
  • Spotify development mode allows up to five authenticated users for one app. Only hosts need to be added; normal players do not.
  • The game’s source code is available at github.com/eladbiller/Hitster, but copying it is optional.

If something goes wrong

“Invalid redirect URI”
Return to Spotify Settings and paste the exact Party address from Step 2 again.
Login works but Party does not
Open Users Management and add the host’s exact Spotify email address. Then wait a minute and try again.
Music will not start
The music host needs Spotify Premium. Then tap Play Song once in Party.
It says the Client ID is invalid
Copy the Client ID from Spotify again. It has 32 letters and numbers; do not use the Client Secret.
